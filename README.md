# LIGHTHOUSE – Cybercrime Awareness Platform

## Project Overview

LIGHTHOUSE is a web-based cybercrime awareness platform developed to educate users about online threats and provide immediate assistance through helplines, maps, chatbot support, and learning resources. The project focuses on improving awareness, accessibility, and user safety.


## Features

### Multi-Language Support

The website supports English, Hindi, and Marathi.
Language selection dynamically updates the content using JavaScript and DOM manipulation.

### Helpline Section

Displays important emergency contact numbers such as:

* National Cybercrime Helpline (1930)
* Police Control Room
* Women Helpline
* Child Helpline
* Cyber Fraud Emergency

### Map Integration

Google Maps is embedded using iframe to help users locate nearby cybercrime help centers and services.

### Chatbot

A rule-based chatbot provides instant responses to user queries related to cybercrime and safety.

### Video Learning Section

Cybersecurity awareness videos are integrated using YouTube.
Videos are loaded dynamically using JavaScript when a user clicks on a thumbnail.

### Login System

A basic login interface is implemented using HTML and JavaScript for user access control.

## Technologies Used

* HTML5 for structure
* CSS3 for styling and layout
* JavaScript for interactivity and logic
* Google Maps Embed (iframe) for location services
* YouTube Embed for video content


## How It Works

* Multi-language functionality is handled using a JavaScript translations object.
* DOM manipulation is used to update content dynamically.
* YouTube videos are loaded using iframe when triggered by user interaction.
* Navigation is managed through multiple linked HTML pages.
* Basic validation and interaction logic are implemented using JavaScript.

## Objective

The main objective of this project is to:

* Spread awareness about cybercrime
* Provide quick access to emergency help
* Educate users through videos and information
* Improve accessibility through multi-language support

## Limitations

* No backend integration
* Login system is basic and not secure
* Chatbot is rule-based, not AI-powered
* Map is static (iframe-based)

## Note

This project is developed for academic purposes and demonstrates frontend web development concepts along with cybersecurity awareness.
